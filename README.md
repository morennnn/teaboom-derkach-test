# Тестовое задание: Верхняя часть карточки товара для Teaboom.ru

Интерактивный блок карточки товара «Ананасовый улун» с адаптивной версткой и переключением фасовок.

## Особенности реализации

- **Чистый HTML5 / CSS3 / Vanilla JS**: Без внешних библиотек и фреймворков.
- **Методология BEM (БЭМ)**: Использование читаемой структуры классов (`.product-card__info`, `.product-card__option-btn` и т.д.).
- **Адаптивность (Responsive)**:
  - `Desktop`: 1440px (двухколоночная Grid-сетка)
  - `Tablet`: 768px (оптимизированные отступы и размеры шрифтов)
  - `Mobile`: 375px (удобная одноколоночная раскладка, увеличенная область клика и удобная сетка фасовок)
- **Интерактив**: Мгновенное обновление цен, старых цен и артикулов при переключении фасовок без перезагрузки страницы.

## Инструкция по запуску

1. Клонировать репозиторий: `git clone https://github.com/morennnn/teaboom-derkach-test.git` или скачать архив.
2. Открыть файл `index.html` в любом современном браузере.
